A.L.V.O

ALVO foi meu primeiro projeto pessoal, feito pra criar uma interatividade maior no meu RPG,
assim os players conseguiriam uma descrição da criatura que encontrassem caso conseguissem o código dela.

porém, como uma database bem simplória, eu sinto que ele pode ter outros usos, e eu planejo expandir e aprimorar o ALVO para ser mais do que apenas uma ferramenta estética precária
